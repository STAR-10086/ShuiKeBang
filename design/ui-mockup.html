还原 iOS 原版的关键结构

  • 红色「正在录音 + 计时器」状态条，常驻转录区顶部
  • 普通讲课行：时间戳（灰）+ 正文；提问独立成卡片，不混入文本流
  • 提问卡片两级：可能被提问（关键词预警）→ 问题回溯（核心问句）
  • 底部悬浮圆形控制组：停止 / 复制 / 问 AI / 标记
  • 命中瞬间：震动 + 顶部胶囊（iOS 灵动岛）展开问题与「有提问」标签

Android 版相对原版的增强

  • 新增模型下载页（iOS 靠系统 Speech 框架，安卓必须动态下发）
  • 中英 / 中英混合识别语言切换、会话搜索、一键问 AI 入口前置
  • Material 3 圆角卡片与 FAB，适配深色模式与大屏/横屏（后置）
  • 电池优化白名单、后台保活引导（小米/vivo 杀后台重灾区）

「安卓灵动岛」四级承接策略（按运行环境自动降级）

说明：本设计稿为 Android 移植方案的界面示意（非官方界面、非真实截图），界面结构与文案依据水课帮 App Store 官方截图、官方实机演示视频转写整理；课堂问题文本为官方演示中的示例。技术选型结论：iOS 版本体仅 1.82MB 是因为使用系统 SFSpeechRecognizer，Android 无等价系统能力，故采用 sherpa-onnx 真流式 Zipformer（中英双语 small，INT8 整套约 28MB，边说边出字）从 GitHub Release 动态下发，APK 本体保持数 MB。
